## Story
**As a** Sales Agent,
**I want** to filter deals by labels and assignees and search for specific contacts,
**so that** I can efficiently manage large pipelines and automate status changes.

## Acceptance Criteria
1. **Server-side Search**: Input no header que filtra contatos por nome em tempo real (debounced).
2. **Filtros de Atribuição**: Seletor para filtrar deals por `assignee_id`.
3. **Filtros de Labels**: Seletor múltiplo para filtrar deals que possuam labels específicas.
4. **Automação de Estágio**: Quando a label `GADS-Qualified` é adicionada a uma conversa, ela deve ser movida automaticamente para o estágio `Qualified` (ID fixo ou configurável).
5. **Responsividade**: Board com `overflow-x-auto` garantindo que colunas não quebrem o layout em telas menores.

## Dev Notes
- **Filtros**: Use os componentes de UI existentes do Chatwoot para manter a consistência (ex: `WootDropdown`).
- **Automação**: O ideal é usar o sistema de `Webhooks` ou `Dispatcher` do Chatwoot para reagir à adição de labels.
- **Performance**: A busca deve ser feita no servidor para suportar milhares de leads.
