## Story
**As a** Integrator,
**I want** to implement the Ruby models and REST endpoints for CRM,
**so that** the frontend can manage pipelines and move deals between stages.

## Acceptance Criteria
1. Model `CrmPipeline` com validações de `presence` e `uniqueness` (account scope).
2. Model `CrmPipelineStage` com ordenação padrão por `position`.
3. Model `Conversation` atualizado com associações para pipeline e stage.
4. Endpoints CRUD para `Pipelines` sob o namespace `api/v1/accounts/:id/crm`.
5. Payload do pipeline deve incluir `conversations_count` para cada stage.
6. Endpoint de listagem de conversas por stage com paginação.
7. Pundit policies garantindo isolamento por `account_id`.
